# Romantiverse Bingo

**Brought to you by the Cheese Louise Podcast**

Standalone movie-trope bingo game, designed for solo and social play. Hallmark-first catalog, with a shared engine for future Christmas, horror, and other genre experiences.

## Project status

Repository initialized. The v0.1 prototype source has not yet been imported into this repository. Do not treat this as a deployed or production-ready game.

## Engineering principles

- Deterministic game logic independent of AI movie analysis.
- Verified movie data distinguished from predicted tropes.
- Reliable marking, win detection, autosave, and recovery.
- Authoritative, idempotent multiplayer scoring when implemented.
- Accessibility, regression tests, and honest test reporting.
